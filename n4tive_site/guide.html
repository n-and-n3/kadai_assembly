01 / GET STARTED

最初のプログラム

プログラム全体を main(){ ... } で囲みます。通常の文には ; が必要です。if と for のブロックの後には付けません。

main.n4
main(){
    input n;
    print n * (n + 1) / 2;
}

標準入力に 5 を渡すと 15 と出力します。C++ の int main()、cin、cout に相当する最小例です。現在、// や /* */ のコメントは使えません。

02 / DATA

変数

int x; で整数変数を宣言し、x = 1; で代入します。整数は64ビットです。ブロックごとのローカルスコープはなく、if や for の中で使った変数もプログラム全体で共有されます。

変数と代入
main(){
    int x;
    int y;
    x = 1;
    y = x * (x + 1) / 2;
    print y;
}

input x; で初めて現れる名前も変数として確保されます。読みやすさのため、入力以外の変数は int で宣言してください。変数名は英字のみで、数字や _ は名前に使えません。

03 / EXPRESSIONS

四則演算と比較

+、-、*、/、% と括弧が使えます。/ は整数除算です。優先順位は C++ と同じく、単項 -、乗除算・剰余、加減算、比較の順です。

算術+ - * / %
比較== != < > <= >=

比較式は真なら 1、偽なら 0 です。例えば x = (a < b); と書けます。&&、||、++、-- は使えないため、必要な条件は if を入れ子にし、更新は x = x + 1; と書きます。

04 / CONTROL FLOW

for / if / break

if (条件){...} else {...} は C++ とほぼ同じで、条件が 0 なら偽です。for(N){...} は C++ の三項 for ではなく、N回繰り返す構文です。N は開始時に一度だけ評価され、ループのカウンタはコードから参照できません。

回数指定ループと早期終了
main(){
    input N;
    int x;
    for(N){
        if (x == 3){
            break;
        }
        x = x + 1;
    }
    print x;
}

break; は最も内側の for だけを抜けます。while はありません。for の回数を十分大きくして条件成立時に break する形で代用できますが、回数の上限までに止まるよう設計してください。

05 / COLLECTIONS

配列

list A[100]; は64ビット整数100個分の配列を確保します。サイズには正の整数リテラルを書きます。添字は C++ と同じ0始まりで、A[i] の読み書きができます。

配列への保存と参照
main(){
    list A[100];
    A[0] = 5;
    A[1] = 7;
    print A[0] + A[1];
}

配列の長さは実行中に変更できません。添字の範囲チェックはありません。 例えば list A[100]; なら 0 から 99 までを使ってください。

06 / INPUT & OUTPUT

入出力

n4tive動作
input x;標準入力から整数を1個読む
print x;整数を出力し、改行する
inputc x;空白を読み飛ばし、次の1文字のコードを整数変数へ読む
printc x;整数値を文字として1文字出力する（改行なし）

文字リテラルはないので、文字を比較・代入するときは文字コードを使います。作者の B のコードは 111 を o、120 を x として扱います。inputc は空白・改行を飛ばすので、空白文字そのものは読み取れません。

07 / REAL PROGRAMS

作者が書いた3つのプログラム

レポートに載せた AtCoder 用のコードです。各「エディタで試す」を押すと、ソース・入力・期待出力がコードテスト画面に入ります。

A配列へ保存して、指定位置を合計

N 個の値を A[0] から順に保存します。後半の for(M) では、1始まりの入力 ind を A[ind-1] に直して合計します。

main(){
    input N;
    input M;
    list A[100];
    int c;
    int x;
    x = 0;
    for(N){
        input a;
        A[x] = a;
        x = x + 1;
    }
    int ans;
    for(M){
        input ind;
        ans = ans + A[ind-1];
    }
    print ans;
}

入力 3 2 / 5 7 9 / 1 3 → 出力 14

B1文字ずつ読み、文字を置換

inputc で読み取った o（111）を、残り回数 K がないとき x（120）へ変えます。printc を繰り返して文字列を作る例です。

main(){
    input N;
    input K;
    for(N){
        inputc x;
        if (x == 111){
            if (K > 0){
                K = K - 1;
            } else {
                x = 120;
            }
        }
        printc x;
    }
}

入力 4 1 / ooxo → 出力 oxxx

C存在表と break で探索

arr[v] = 1 を「値 v がある」の印にします。x = 0 から順に調べ、最初の未出現値で break します。for(K) は探索回数の上限です。

main(){
    input N;
    input K;
    list arr[300001];
    
    for(N){
        input tmp;
        if (tmp <= 300000){
            arr[tmp] = 1;
        }
    }
    
    int x;
    for(K){
        if(arr[x] == 0){
            break;
        }
        x = x + 1;
    }
    
    print x;
}

入力 4 5 / 0 1 3 4 → 出力 2
